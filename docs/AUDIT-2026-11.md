## Domain Verdicts

### 1. Stability & Crash — one real gap found and closed

The import hardening (`89154ed`) stopped new poison at the front door, but the cross-check revealed a **parity gap**: four consumers still trusted raw storage contents on read.

| Consumer | Poison vector before fix |
| --- | --- |
| `BmiHistorySparkline.loadHistory` | Manual `JSON.parse` — NaN/Infinity scaling, silently blank chart |
| `BmiSnapshot.refreshBestBmi` | Best-BMI reduce over raw records — Infinity "best BMI" badge |
| `BmiForm.handleExportClick` | Raw record count in the export summary |
| `saveBmiToHistory` write-back | Re-persisted poison indefinitely |

Records can predate the import hardening or enter via `restoreLatestBackup`, which restores raw snapshot values from IndexedDB without record validation.

**Fix (`3cff019`):** exported the hardened `isValidRecord`/`toRecord` pair from `history-io.ts` and added a single validated accessor `readBmiHistory()` in `bmi-history.ts` (never throws; malformed JSON, non-array payloads, and invalid records degrade to a shorter sorted list). `saveBmiToHistory` is now self-healing: every save rewrites storage with validated records only. `restoreLatestBackup` needs no change — the read side neutralizes whatever the restore writes.

**Ultra-scale note:** extreme JSON numbers (`1e999` → `Infinity`) are the primary poison vector and are now rejected on **every** path records can take into the UI. Verified TDD-first with a raw `1e999` JSON literal test that fails against the old read paths.

### 2. Code Hygiene (dragon hunt) — two dragons found, slain

- **Zombie static-deploy era (`007156f`):** `svelte.config.static.js` was referenced by no build, script, or doc — only tolerant workflow path filters and a `|| true` release-staging copy. Removed together with its `@sveltejs/adapter-static` devDependency and all dead references.
- **Duplicate parse/classification logic (`89154ed`, `3cff019`):** CSV export duplicated classification thresholds (now reuses `classifyBmi`/`getCategoryLabel`); three duplicate `JSON.parse` sites consolidated behind `readBmiHistory()`.

**Dependency scan:** 34 dependencies checked against actual imports and configs. `prettier`, `prettier-plugin-svelte`, `svelte-check` (build.sh scripts), `postcss`/`autoprefixer` (`postcss.config.js`), `@types/bun` (TS types for Bun APIs) all verified in use. **Script scan:** all 9 scripts referenced (the `audit-core-files.ts` collector backs `check-loc.ts`/`check-headers.ts`). **TODO/FIXME/eval/dead-code sweeps:** zero occurrences (consistent with the August audit).

### 3. Optimization — one payload win, rest at peak (skip justified)

- **Fixed (`6c7c8d4`):** the 1254×1254 brand master (1.0 MB) sat in `static/`, so the unfiltered service-worker precache downloaded and cached it on every install while nothing ever rendered it. Moved to `docs/assets/` — still in-repo and in the release source archive (which copies `docs/`), gone from the shipping payload. Install icons stay pixel-identical because all web-facing derivatives (192–1024) are untouched.
- **Measured state:** 1.1 MB immutable client (raw; roughly a third over the wire), largest chunk 440 KB (minified app/vendor code — no accidental library pulls: zero lucide/i18n string markers in the vendor chunk), 93 KB CSS, ~1.5 MB static assets (down from ~2.5 MB).
- **Skip justification:** the BMI computation hot path is a single guarded division per keystroke with runes `$derived` wiring — nothing to profile; further chunk splitting or i18n lazy-loading would trade regression risk in a dormant project for marginal wire savings. The 724 KB 1024 px manifest icon is the one remaining heavy asset, but it is functionally referenced (install visuals) and replacing it with the 512 derivative could change launcher icon selection on some platforms — an owner decision, not an audit unilateral call.

### 5. LTS Stability — hidden failure modes closed across both audit legs

- **CI endurance (`c6cdea5`):** every scheduled and push-triggered job now has an explicit `timeout-minutes`; the self-heal workflow fetches + rebases between push attempts and fails loudly.
- **Version pinning:** CI resolves the Bun version from `packageManager` with a fail-closed check; `bun install --frozen-lockfile` everywhere; `engines` node `>=22 <25`; dependency changes flow only through the lockfile-only weekly maintenance.
- **PWA freshness:** manifest cache-buster bumped so installed clients re-fetch `manifest.json`.
- **Docs accuracy:** CHANGELOG, BRANDING, and cross-references updated in the same commits as every fix; no stale license or path references remain (checked by grep + `check-branding`).
